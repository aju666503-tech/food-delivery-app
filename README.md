# QuickBite Food Delivery System

A desktop-based food delivery application built with Python and Tkinter, structured using Object-Oriented Programming (OOP) principles.

## Features
* **User Profile & Address Setup**: Customize customer details and delivery locations.
* **Interactive Menu**: Browse available fast food items[cite: 1] and beverages[cite: 1] with dynamic pricing.
* **Order Management**: Add items to your cart and track the running total[cite: 2].
* **Checkout System**: Supports Cash on Delivery (COD) with change calculation and Credit Card payments[cite: 2].
* **System Logging**: Real-time terminal logs tracking the order lifecycle from preparation to delivery.

## Project Structure
* `main.py`: Contains core backend classes (User, Customer, Menu, MenuItem, Order, Payment, Delivery)[cite: 1].
* `ui.py`: Handles the Tkinter graphical user interface and event workflows[cite: 2].
